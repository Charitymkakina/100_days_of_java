# Access Modifiers
Access modifiers they control who is able to access a class, a variable and a method.

# Types of Access Modifiers
1. `Public` - The class is accessible by any ather class.
2. `Private` - The code is only accessible within the declared class.
3. `Default` - The code is only accessible in the same package used when no modifier has been specified.
4. `Protected` - Code is accessible in the same package and sub-classes.
