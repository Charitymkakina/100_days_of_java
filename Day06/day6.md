# Java Packages and APIs
`Package` used to group related classes. It is a folder.

There are: `Built-in packages` a library of priwritten classes thata are free to use. A libary is divided into packages and classes

To use a class or package from the library we use the `import` keyword
 
 Example: `import package.name.class;`
          `import package.name.*;`

# Import a class
using `Scanner` class which is used to get user input we use the `import java.util.Scanner;`

`java.util` is a package while `Scanner` is a class of the java util package.


# Import a package
To import a whole package, end the sentence with an asterisk sign (*).

Example: `import java.util.*;`
