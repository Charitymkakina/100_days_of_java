# Day 2 - Constructors

# What I Learned

A constructor is a special block of code that is automatically called when an object is created using the `new` keyword.

Constructors are used to initialize object attributes when an object is created.

# Key Concepts

# Constructor
A constructor has the same name as the class and does not have a return type.

# this Keyword
The `this` keyword refers to the current object.

Example:
this.name = name;
